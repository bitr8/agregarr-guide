# Collections

An Agregarr collection saves a source such as a TMDB chart or Trakt list, a library, a name and where it appears in Plex. Creating the collection saves those settings. On each sync, Agregarr matches the source against the titles you own and builds the Plex collection, so the row stays up to date.

If you haven't made one yet, start with [Your first collection](../get-started/first-collection.md).

## Set up a collection

- [Choose a source](choose-a-source.md): which source suits the row you have in mind and what each one needs.
- [Add a Trending or Popular row](make-trending.md): TMDB, Trakt or IMDb charts.
- [Turn a list into a collection](list-to-collection.md): a Trakt, IMDb, Letterboxd or MDBList list.
- [Add a streaming Top 10 or Originals row](streaming-top-10.md): follow what a streaming service is showing.
- [Add an anime collection](anime.md): AniList and MyAnimeList charts and lists.
- [Make collections from your own library](from-your-library.md): genre, decade, director, label or tag.
- [Show what people request and watch](requests-and-watching.md): Seerr, Tautulli and Tracearr.
- [Rotate several lists through one row](cycle-sources.md): take turns between lists.
- [Run a collection only at certain times](timed.md): date ranges and days of the week.
- [Name collections](name-collections.md): titles, variables and sort titles.
- [Posters, wallpapers and theme music](posters.md): artwork for the collection itself.
- [Move collections between servers](move-between-servers.md): export and import.
