# Agregarr (bitr8 fork) Guide

Documentation for the features specific to the [bitr8/agregarr](https://hub.docker.com/r/bitr8/agregarr) fork. Published at https://bitr8.github.io/agregarr-guide/. Built with [Zensical](https://zensical.org).

## Preview locally

Requires [uv](https://docs.astral.sh/uv/).

```bash
uv run zensical serve
```

Open http://localhost:8000. To build the static site into `site/`:

```bash
uv run zensical build --clean
```

## Contributing

Fixes are welcome, small ones included. Every page has an edit button that opens the file on GitHub, so most changes need nothing installed. See [Contributing](https://bitr8.github.io/agregarr-guide/Contributing/) for the full guide.
