# Contributing

Fixes to these docs are welcome, small ones included. The full guide is on the site: https://bitr8.github.io/agregarr-guide/Contributing/

Short version: edit the Markdown under `docs/`, preview with `uv run zensical serve`, and open a pull request against `main`. The build runs on every pull request.

Bugs in the app itself go to https://github.com/bitr8/agregarr-dev/issues.

By sending a pull request you agree your change is published under CC BY 4.0.
