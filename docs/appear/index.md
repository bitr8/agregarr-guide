# Where collections appear

A collection can appear in three places in Plex: your Home, other people's Home and the library's Recommended tab. Every collection also appears in the library's Collections tab. This section covers how Agregarr decides what goes where, in what order and how to keep those rows changing.

Start with [Home, Recommended and Library explained](home-recommended-library.md) if the pages in Agregarr don't match what you see in Plex.

## Goals

- [Order the rows on Plex Home](order-home.md): drag rows into place and check when Plex picks up the new order.
- [Shuffle the Home order](shuffle-home.md): shuffle selected rows on a schedule.
- [Show a different set of collections on Home](rotation.md): rotate a few Home rows through a larger set.
- [Promote collections above the A-Z list](promote-library.md): set the order of the library's Collections tab.
- [Replace Plex's Recently Added row without placeholders](recently-added.md): create a Recently Added row that leaves placeholders out.
